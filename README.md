# DAS Kai

DAWの音を、仮想オーディオデバイスなしでOBSに送るプラグインです。DawAudioStreamer(yoruhinot 作)を改造し、次の3つを足しています。

- **クロックずれの吸収**: DAWのオーディオインターフェースとMac本体は別々の時計で動いています。そのずれを再生速度のごくわずかな伸び縮み(数十ppm、音程にして0.1セント未満)で吸収し、長時間の配信でも歌とOBSの他の音の合い方が変わらないようにします。
- **時刻の受け渡しと遅延の自動補正**: 音がDAWで処理された時刻をOBSに渡します。OBSはその時刻に合わせて音を置きます。プラグインからOBSまでの受け渡しの遅れは自動で差し引かれます。配信と録画では、映像も同じ時刻を基準に並べられます(OBSのソースコードで確認。実機の録画での確認はまだです)。
- **手動補正**: 歌い手がオケを聞く経路の遅れなど、プラグインから測れない分を手で足せます。

対応環境は macOS 13 以降の Apple Silicon、OBS 32 系です。Windows には対応していません。

## 入れ方

ビルドしてから、付属のスクリプトで入れます。入る場所はこのユーザーの3か所だけです。

```bash
scripts/install.sh
```

- `~/Library/Audio/Plug-Ins/VST3/DAS Kai.vst3`
- `~/Library/Audio/Plug-Ins/Components/DAS Kai.component`
- `~/Library/Application Support/obs-studio/plugins/das-kai-obs.plugin`

元の DawAudioStreamer とは名前も中身の識別子も別なので、両方入れたままで構いません。

## 使い方

1. DAW を開き直し、マスターの最後に「DAS Kai」を1個挿します(VST3 か AU)。
2. OBS を開き直し、「ソース」の[＋]から「DAS Kai（DAW）」を追加します。設定は不要です。
3. DAW を再生し、プラグイン画面の OBS 欄が「受信中」になることを確かめます。

## プラグイン画面の見方

画面は日本語で開きます。右上の[English]で英語表示に切り替えられ、選んだ言語は DAW のプロジェクトに保存されます。

| 表示 | 意味 |
|---|---|
| OBS 欄の「受信中」/「待機中」 | OBS が受け取っていれば「受信中」。「待機中」は OBS 側のソースがまだない状態 |
| 時計のずれ +23 ppm | DAW の時計が Mac 本体より何 ppm 速いか。起動直後は「時計を合わせています…」 |
| 「OBSでの位置」の大きな数字 | OBS の中で、DAW の音を何ミリ秒前に置いているか(自動 + 手動)。変えた直後は「反映中…」と出て、OBS に反映されると数字が変わります。合計は 850 ミリ秒が上限です |
| 自動補正 | 受け渡しの遅れを自動で差し引くかどうか。通常はオン |
| 手動補正 | 手で足す補正(-500〜+500 ミリ秒)。プラスは「もっと前に置く」。ダブルクリックで 0 に戻ります |

## 手動補正の値の決め方

歌い手がオケを聞く経路の遅れ(ブラウザ → スピーカーやヘッドホン)は、機材と聞き方が同じなら毎回同じです。一度測れば使い回せます。

1. OBS の録画を「トラックを分けて保存」にし、オケ(ブラウザ)と DAS Kai を別トラックにします。
2. オケの拍に合わせて、マイクの前で手を数回たたいて録画します。
3. 録画を DAW や編集ソフトに読み込み、オケの拍と手拍子の波形のずれをミリ秒で測ります。
4. 手拍子が遅れていれば、その値を「手動補正」に入れます。

## 知っておくこと

- 手動補正や自動補正を変えると、OBS の音が一瞬途切れます。ふつうは 0.1 秒前後で、OBS に新しい時刻を受け入れさせるための切れ目です。手動補正を大きく減らした時は、減らした分だけ長く途切れます(-500 ミリ秒なら約 0.5 秒)。配信中ではなく、準備の時に合わせてください。
- OBS は、遅れて届く音に合わせて全体の待ち時間を自動で増やします。一度増えた待ち時間は、OBS を開き直すまで減りません。配信と録画の音と映像は揃ったままです。
- OBS の画面のプレビューとモニター音は、この待ち時間の分だけずれて見えることがあります。配信と録画には影響しません。
- DAW の書き出し(バウンス)中は送りません。バイパス中は無音を送ります。
- 旧仮称「Kinu Stream」で OBS に追加したソースは、そのまま DAS Kai のソースとして動きます。ソースの名前だけは古いままなので、必要なら OBS で名前を変えてください。
- 送れるのは、同じユーザーで同時に 1 個だけです。2 個目は画面に「1個のみ」と出ます。
- Cubase の ASIO-Guard など、DAW が先読みで処理する設定での動きは未確認です。先読みの分だけ自動補正が多めにかかる可能性があり、その場合は手動補正をマイナスにして合わせます。
